# Where can I find UCL AI Society tutorials and notebooks?

The tutorial library is at https://uclai.co.uk/our-initiatives/tutorials/. It lists published tutorials and notebooks from the shared knowledge folder, alongside the earlier 2023/24 and 2024/25 series. Earlier 2020/21, 2021/22 and 2022/23 materials are linked through their GitHub repositories.

Reviewed files added to `knowledge/tutorials/` appear in both that website library and MCP search after merging and successful deployment. Nexus session notes use `knowledge/nexus/` and appear on https://uclai.co.uk/our-initiatives/Nexus-Labs/#session-notes as well as in the MCP.

Use the published entries and their academic-year metadata to establish which materials are available. Session dates describe learning resources; upcoming sessions and events come from the official Luma calendar. Older archive links may no longer be maintained. If material is missing, ask info@uclai.co.uk rather than assuming it exists.
